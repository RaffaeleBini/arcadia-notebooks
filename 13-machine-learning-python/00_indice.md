# Machine Learning y Python for Dummies

Bienvenido o bienvenida a este manual. Está pensado para acompañarte desde cero: no necesitas
haber programado antes en proyectos complejos, ni saber álgebra lineal, ni tener experiencia
previa con inteligencia artificial (IA). Solo te hace falta curiosidad y ganas de practicar.

Este manual reorganiza el contenido oficial de la certificación EITC/AI/MLP (European IT
Certification / Artificial Intelligence / Machine Learning with Python) en doce capítulos
agrupados en cinco bloques temáticos, con una progresión gradual: primero usas los algoritmos ya
construidos con scikit-learn y después los programas tú mismo, desde cero, para entender su
funcionamiento interno.

## Cómo usar este manual

Cada capítulo sigue la misma estructura: por qué te importa el tema, una explicación conceptual
apoyada en una analogía cotidiana, un ejemplo de código real y comentado, un resumen con los
puntos clave, y una sección **"Ponlo en práctica"** con una mini-tarea para que apliques lo
aprendido de inmediato.

**Empieza por el capítulo 1** aunque ya tengas experiencia con Python: te sitúa el mapa completo
del curso y te asegura que tu entorno de trabajo está listo para el resto de capítulos.
