# TensorFlow Quantum Machine Learning for Dummies

Bienvenido o bienvenida a este manual. Aquí aprendes, paso a paso y desde cero, a combinar computación cuántica con machine learning usando TensorFlow Quantum (TFQ). No necesitas experiencia previa en álgebra lineal, física cuántica ni Python avanzado: solo curiosidad y ganas de programar.

## Glosario de siglas y acrónimos

Antes de arrancar, aquí tienes todas las siglas que vas a encontrarte en el manual, ordenadas alfabéticamente con su nombre completo. Vuelve a esta lista siempre que te cruces con una sigla que no recuerdes.

| CPU | Unidad Central de Procesamiento (Central Processing Unit) |
| DRAG | Eliminación Derivativa por Puerta Adiabática (Derivative Removal by Adiabatic Gate) |
| GPU | Unidad de Procesamiento Gráfico (Graphics Processing Unit) |
| IA | Inteligencia Artificial |
| KS | Prueba de Kolmogorov-Smirnov (Kolmogorov-Smirnov test) |

| ML | Aprendizaje Automático (Machine Learning) |
| NISQ | Cuántico de Escala Intermedia y Ruidoso (Noisy Intermediate-Scale Quantum) |
| NLP | Procesamiento del Lenguaje Natural (Natural Language Processing) |

| QAOA | Algoritmo Cuántico Aproximado de Optimización (Quantum Approximate Optimization Algorithm) |
