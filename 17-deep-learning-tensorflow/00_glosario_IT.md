# Glossario di sigle e acronimi

Prima di iniziare, qui trovi il significato delle sigle che incontrerai nel manuale, ordinate alfabeticamente.

- **API**: Application Programming Interface (interfaccia di programmazione di applicazioni)
- **AUC-ROC**: Area Under the Curve — Receiver Operating Characteristic (area sotto la curva ROC, una metrica di valutazione)
- **CNN**: Convolutional Neural Network (rete neurale convoluzionale)
- **CPU**: Central Processing Unit (unità centrale di elaborazione)
- **CT**: Computed Tomography (tomografia computerizzata)
- **CUDA**: Compute Unified Device Architecture (architettura di calcolo NVIDIA per usare la GPU in compiti generici)
- **DL**: Deep Learning (apprendimento profondo)
- **DQN**: Deep Q-Network (rete Q profonda, un algoritmo di apprendimento per rinforzo)
- **GPU**: Graphics Processing Unit (unità di elaborazione grafica)
- **GRU**: Gated Recurrent Unit (unità ricorrente con gate)
- **IA**: Intelligenza Artificiale
- **JS**: JavaScript
- **JSON**: JavaScript Object Notation (formato di scambio dati)
- **LSTM**: Long Short-Term Memory (memoria a breve-lungo termine, un tipo di cella ricorrente)
- **ML**: Machine Learning (apprendimento automatico)
- **MLP**: Multi-Layer Perceptron (perceptrone multistrato, una rete densa classica)
- **MSE**: Mean Squared Error (errore quadratico medio)
- **NLP**: Natural Language Processing (elaborazione del linguaggio naturale)
- **NMT**: Neural Machine Translation (traduzione automatica neurale)
- **PPO**: Proximal Policy Optimization (un algoritmo di apprendimento per rinforzo)
- **ReLU**: Rectified Linear Unit (unità lineare rettificata, una funzione di attivazione)
- **RL**: Reinforcement Learning (apprendimento per rinforzo)
- **RNN**: Recurrent Neural Network (rete neurale ricorrente)
- **SGD**: Stochastic Gradient Descent (discesa del gradiente stocastico)
- **SQL**: Structured Query Language (linguaggio di interrogazione strutturato)
- **TF**: TensorFlow
- **TFX**: TensorFlow Extended (insieme di strumenti TensorFlow per la produzione)
- **TPU**: Tensor Processing Unit (unità di elaborazione tensore)
