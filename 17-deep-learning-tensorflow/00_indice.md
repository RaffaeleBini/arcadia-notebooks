# Deep Learning con TensorFlow for Dummies

Bienvenido a este manual. Aquí aprendes deep learning con TensorFlow desde cero,
sin dar por hecho que ya sabes Python avanzado, álgebra lineal o machine learning.
Cada capítulo combina teoría, una analogía para fijar el concepto, código comentado
y una mini-tarea para que practiques.
