# Glosario de siglas y acrónimos

Antes de empezar, aquí tienes el significado de las siglas que vas a encontrar a lo
largo del manual, ordenadas alfabéticamente.

- **API**: Application Programming Interface (interfaz de programación de aplicaciones)
- **AUC-ROC**: Area Under the Curve — Receiver Operating Characteristic (área bajo
  la curva ROC, una métrica de evaluación)
- **CNN**: Convolutional Neural Network (red neuronal convolucional)
- **CPU**: Central Processing Unit (unidad central de procesamiento)
- **CT**: Computed Tomography (tomografía computarizada)
- **CUDA**: Compute Unified Device Architecture (arquitectura de cómputo de NVIDIA
  para usar la GPU en tareas generales)
- **DL**: Deep Learning (aprendizaje profundo)
- **DQN**: Deep Q-Network (red Q profunda, un algoritmo de aprendizaje por refuerzo)
- **GPU**: Graphics Processing Unit (unidad de procesamiento gráfico)
- **GRU**: Gated Recurrent Unit (unidad recurrente con puertas)
- **IA**: Inteligencia Artificial
- **JS**: JavaScript
- **JSON**: JavaScript Object Notation (formato de intercambio de datos)
- **LSTM**: Long Short-Term Memory (memoria a largo-corto plazo, un tipo de célula
  recurrente)
- **ML**: Machine Learning (aprendizaje automático)
- **MLP**: Multi-Layer Perceptron (perceptrón multicapa, una red densa clásica)
- **MSE**: Mean Squared Error (error cuadrático medio)
- **NLP**: Natural Language Processing (procesamiento del lenguaje natural)
- **NMT**: Neural Machine Translation (traducción automática neuronal)
- **PPO**: Proximal Policy Optimization (un algoritmo de aprendizaje por refuerzo)
- **ReLU**: Rectified Linear Unit (unidad lineal rectificada, una función de
  activación)
- **RL**: Reinforcement Learning (aprendizaje por refuerzo)
- **RNN**: Recurrent Neural Network (red neuronal recurrente)
- **SGD**: Stochastic Gradient Descent (descenso de gradiente estocástico)
- **SQL**: Structured Query Language (lenguaje de consulta estructurado)
- **TF**: TensorFlow
- **TFX**: TensorFlow Extended (conjunto de herramientas de TensorFlow para
  producción)
- **TPU**: Tensor Processing Unit (unidad de procesamiento tensorial)
