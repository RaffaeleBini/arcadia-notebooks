# 00. Prologo e glossario di acronimi

## Perché questo manuale

Imparare TensorFlow non significa memorizzare funzioni: significa capire come
una macchina può imparare pattern dai dati invece di seguire regole
che tu stesso programmi a mano. Questo manuale ti accompagna dalla prima rete
neurale con una sola neurone fino a portare un modello in produzione, con esempi
di codice che puoi eseguire tu stesso in Google Colab, senza installare nulla sul tuo
computer.

Ogni capitolo segue la stessa struttura: prima ti spiega perché l'argomento
è importante, poi il concetto con analogie concrete, quindi un esempio di codice
commentato e, infine, un riassunto e un mini-esercizio per metterlo in pratica. Se preferisci
imparare facendo, ogni capitolo ha anche la sua lezione con due notebook: uno di teoria, per
seguire la spiegazione in diretta, e
uno di pratica, con esercizi che risolvi tu e la cui soluzione puoi
consultare quando ne hai bisogno.

Non è necessario che tu sappia algebra lineare o che tu domini Python a fondo. È comunque
utile che tu abbia nozioni di base di programmazione (variabili, cicli,
funzioni) e voglia di sperimentare: nel Machine Learning si impara soprattutto
provando.

| Acronimo | Nome completo |
|---|---|
| AI / IA | Artificial Intelligence / Intelligenza Artificiale |
| API | Application Programming Interface (Interfaccia di Programmazione di Applicazioni) |
| CNN | Convolutional Neural Network (Rete Neurale Convoluzionale) |
| CSV | Comma-Separated Values (Valori Separati da Virgole) |
| EDIH | European Digital Innovation Hub (Hub Europeo di Innovazione Digitale) |
| EITC | European IT Certificate (Certificato Europeo di Tecnologie dell'Informazione) |
| GPU | Graphics Processing Unit (Unità di Elaborazione Grafica) |
| JSON | JavaScript Object Notation |
| LSTM | Long Short-Term Memory (Memoria a Lungo-Breve Termine) |
| ML | Machine Learning (Apprendimento Automatico) |
| NLP | Natural Language Processing (Elaborazione del Linguaggio Naturale) |
| NSL | Neural Structured Learning (Apprendimento Strutturato Neurale) |
| RNN | Recurrent Neural Network (Rete Neurale Ricorrente) |
| TF | TensorFlow |
| TFDV | TensorFlow Data Validation |
| TFMA | TensorFlow Model Analysis |
| TFT | TensorFlow Transform |
| TFX | TensorFlow Extended |
| TPU | Tensor Processing Unit (Unità di Elaborazione Tensoriale) |

## Come usare il manuale insieme al corso

1. Leggi il capitolo corrispondente alla lezione prima o dopo la sessione in
   diretta, secondo il tuo ritmo.
2. Apri il notebook di teoria della lezione in Google Colab ed eseguilo cella per
   cella mentre ripassi il capitolo.
3. Completa il notebook di pratica da solo: prova ogni esercizio prima
   di visualizzare la soluzione.
4. Consulta [TEMARIO_IT.md](../TEMARIO_IT.md) per vedere il percorso completo del corso
   e cosa ti serve per ogni lezione.

Inizia dal capitolo 1 e costruisci la tua prima rete neurale in meno di dieci
minuti!
