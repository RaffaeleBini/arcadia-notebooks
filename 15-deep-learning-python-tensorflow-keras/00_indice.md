# Deep Learning con Python, TensorFlow y Keras for Dummies

Bienvenido o bienvenida a este manual. Aquí aprendes deep learning desde cero: sin álgebra lineal previa, sin experiencia en Machine Learning (ML) y sin necesidad de ser una experta en Python. Solo hace falta que sepas escribir y ejecutar código Python básico.

## Cómo usar este manual

Cada capítulo sigue la misma estructura: por qué importa el tema, la explicación conceptual con analogías, un ejemplo de código comentado, un resumen de puntos clave, y una sección "Ponlo en práctica" con una mini-tarea para ti. Lee los capítulos en orden: cada uno se apoya en el anterior.
